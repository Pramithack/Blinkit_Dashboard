#Blinkit Dashboard
🧠 Project Explanation

The Blinkit Sales Dashboard is a data analytics project built using Power BI to analyze Blinkit’s sales performance across various outlets and product categories.This dashboard was designed to help the business understand sales trends, outlet performance, and consumer behavior by using key metrics such as total sales, average sales, number of items sold, and product ratings.The goal of this project is to turn raw retail sales data into meaningful insights that help management make data-driven decisions.
#🎯 Project Objectives

Analyze total and average sales across all Blinkit outlets.

Understand sales distribution by outlet type, size, and location tier.

Identify top-performing categories like snacks, dairy, and fruits.

Study how fat content and establishment year impact sales.

Provide interactive filters for users to explore the data dynamically.
