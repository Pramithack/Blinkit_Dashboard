# 🟢 Blinkit Sales Dashboard – Power BI Project

## 🧠 Project Explanation  
The **Blinkit Sales Dashboard** is a Power BI project developed to analyze Blinkit’s sales performance across different outlets and product categories.  
This dashboard helps visualize key metrics such as total sales, average sales, item count, and customer ratings, providing deep insights into sales trends and outlet performance.  
The goal is to transform raw grocery sales data into meaningful insights that can support data-driven business decisions.

---

## 🎯 Project Objectives  
- Analyze **total and average sales** across all Blinkit outlets.  
- Understand how **outlet type, size, and location tier** affect performance.  
- Identify **top-selling categories** like Snacks, Dairy, and Fruits.  
- Study the effect of **item fat content and outlet establishment year** on sales.  
- Provide **interactive visualizations and filters** for easier analysis.

---

## 📊 Dashboard Features  

| Feature | Description |
|----------|--------------|
| 💰 **Key Performance Indicators (KPIs)** | Displays Total Sales, Average Sales, Total Items, and Average Rating |
| 📈 **Trend Analysis** | Line chart showing sales trends over outlet establishment years |
| 🏪 **Outlet Insights** | Comparison of performance across outlet types, sizes, and location tiers |
| 🍔 **Item Analysis** | Sales distribution by item type and fat content |
| 🎛️ **Interactive Filters** | Allows filtering by outlet type, size, and item category for customized insights |

---

## 📈 Key Insights  

- **Total Sales:** $1.2M  
- **Average Sales per Item:** $141  
- **Total Items Sold:** 8,523  
- **Average Rating:** 3.92 ⭐  
- **Tier 1 outlets** contribute approximately **71% of total sales**.  
- **Medium-sized outlets** show higher sales consistency.  
- **Fruits, Snacks, and Dairy** are the top-performing categories.  
- Products with **Regular fat content** slightly outperform those with Low Fat.

## 🛠️ Tools and Technologies Used  

- **Power BI Desktop** → Dashboard design and data visualization  
- **Excel / CSV Dataset** → Data source  
- **Power Query Editor** → Data cleaning and transformation  
- **DAX (Data Analysis Expressions)** → Calculated columns and measures  
- **Data Modeling** → Establishing relationships between attributes  

---

## ⚙️ Project Workflow  

1. **Data Import:** Imported the Blinkit dataset (`BlinkIT_Grocery_Data.csv`) into Power BI.  
2. **Data Cleaning:** Removed nulls, standardized categories (e.g., Low Fat/Regular), and verified numeric data types.  
3. **Data Modeling:** Established relationships between item and outlet attributes.  
4. **DAX Measures:** Created custom measures such as Total Sales, Average Sales, and Average Rating.  
5. **Visualization Design:** Added KPIs, charts, filters, and interactive visuals in a user-friendly layout.  
6. **Dashboard Formatting:** Applied Blinkit-themed colors (Yellow, Green, and White) for a clean, branded design.  
7. **Insight Generation:** Analyzed key findings and summarized actionable insights.
